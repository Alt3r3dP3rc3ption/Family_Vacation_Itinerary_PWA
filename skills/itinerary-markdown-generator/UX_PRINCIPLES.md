# UX Principles

## Principle 1

Normal users should never need to edit JSON.

## Principle 2

Normal users should never need to write Markdown.

## Principle 3

Every advanced feature should have a simple equivalent.

Example:

Advanced:
- Upload JSON

Simple:
- Fill out a form

## Principle 4

Google Maps links are first-class inputs.

Users naturally collect places using Google Maps.

The application should leverage that behavior.

## Principle 5

The application should generate structure automatically whenever possible.

## Principle 6

The user should focus on planning the trip, not formatting data.

## Principle 7

Family-focused design takes priority over developer-focused design.
