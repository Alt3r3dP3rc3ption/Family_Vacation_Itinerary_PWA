# Itinerary Generation Prompt

Generate a Markdown itinerary that follows the Family Vacation Itinerary PWA schema.

Requirements:

1. Start with a single H1 trip title.
2. Include Dates and Basecamp metadata.
3. Include a short italic trip summary.
4. Create one H2 section per day.
5. Use bullet-point activities with bold labels.
6. Include a Places Directory section.
7. Organize places into logical categories.
8. Add Website and Map links whenever available.
9. Keep place names consistent across the itinerary and directory.
10. Output only valid Markdown.

Preferred categories:

- Attractions
- Food & Dining
- Transit
- Stays
- Shopping & Leisure
- Museums & History
- Parks & Outdoors
- Day Trips

The final document should be ready for direct upload into the Family Vacation Itinerary PWA.
