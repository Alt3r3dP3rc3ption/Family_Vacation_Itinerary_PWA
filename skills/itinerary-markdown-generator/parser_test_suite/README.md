# Parser Test Suite

This directory contains test scenarios for validating itinerary imports.

Recommended tests:

1. Minimal valid itinerary.
2. Full itinerary with Places Directory.
3. Missing Dates metadata.
4. Missing Basecamp metadata.
5. Missing Places Directory.
6. Duplicate place names.
7. Malformed links.
8. Unicode and emoji handling.
9. Multi-country itineraries.
10. Large itinerary stress test.

Use validator.py and import-readiness-checker.py against each sample.
